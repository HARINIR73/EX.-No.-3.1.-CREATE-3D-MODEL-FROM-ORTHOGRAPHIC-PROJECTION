# EX. No.3.1. CREATE 3D MODEL FROM ORTHOGRAPHIC PROJECTION
## DATE:02.11.26

## AIM:
To create a 3D model from given orthographic projection.

## REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:
Open Autodesk Fusion 360 software and create a new design.
Select the XY plane and click on Create Sketch.
Draw the main rectangular block using the Rectangle tool.
<img width="640" height="97" alt="Screenshot 2026-11-16 032636" src="https://github.com/user-attachments/assets/3c9b88fa-09f9-429a-b20a-d8cc455f3c63" />
Create circular holes in the semicircular portions using the Circle tool.
Apply the required dimensions using the Dimension (D) tool.
Click on Finish Sketch and use the Extrude command to provide thickness to the main block.
<img width="751" height="222" alt="Screenshot 2026-11-16 032831" src="https://github.com/user-attachments/assets/21aca71a-42a6-4ee7-bd26-b1335488397b" />
Check the final 3D model from different views and save the design.
