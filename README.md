# EX. No.3.1. CREATE 3D MODEL FROM ORTHOGRAPHIC PROJECTION
## DATE:02.11.26

## AIM:
To create a 3D model from given orthographic projection.

## REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:
1. Sketch the side profile: Start a new 2D sketch on the vertical side plane and draw a rectangle with a tangent semicircle on the left end.
 
2. Draw the pin hole: Sketch a smaller circle inside the semicircle, sharing the exact same center point.
 
3.<img width="482" height="167" alt="Screenshot 2026-11-17 222350" src="https://github.com/user-attachments/assets/7513e658-af7a-4759-bc29-aba834e45977" />

4. Extrude the main block: Finish the sketch and Extrude the profile symmetrically to form the full width of the clevis body with a through-hole.

5.<img width="437" height="522" alt="Screenshot 2026-11-17 215440" src="https://github.com/user-attachments/assets/65a8fa86-8b87-4761-a172-cc8f7527874d" />
 
6. Start the slot sketch: Create a new sketch on the top flat face of the rectangular block.

7. Draw the U-slot: Sketch a centered rectangle extending from the curved left edge partially into the main block.
   
8. Cut the center gap: Finish the sketch and Extrude the rectangle downward using the Cut operation to form the two fork arms.

9. <img width="906" height="152" alt="image" src="https://github.com/user-attachments/assets/bf8e960d-a6b0-4178-bc93-ef1dbbb47bc5" />
 
10. Sketch the shaft: Start a new sketch on the flat back vertical face of the clevis body.
 
11. Draw the shaft circle: Sketch a circle centered on the back face to define the cylindrical rod diameter.

12. <img width="738" height="77" alt="Screenshot 2026-11-17 222807" src="https://github.com/user-attachments/assets/64171cad-a199-4744-9506-71fbc429c072" />
 
13. Extrude the shaft: Finish the sketch and Extrude the circle outward using the Join operation to create the solid shaft.
